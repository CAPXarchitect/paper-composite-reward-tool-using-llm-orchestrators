# Composite Multi-Component Reward Functions for Tool-Using LLM Orchestrators

Project page for the **in-progress** draft paper *Composite Multi-Component Reward Functions for Tool-Using LLM Orchestrators: A 16-Trace Characterisation* (Rushit Parmar, 2026).

- **Read online:** https://capxarchitect.github.io/paper-composite-reward-tool-using-llm-orchestrators/
- **Repository:** https://github.com/capxarchitect/paper-composite-reward-tool-using-llm-orchestrators

> **Status: working draft.** Content may change between revisions.

The web page is the current version of the draft.

## Updating after a revision

1. Update the changed text in `index.html` (and any figures in `figures/`).
2. Change the "last updated" date in the status line near the top of `index.html`.

## Contents

| Path | What it is |
|---|---|
| `index.html` | The paper as a single static web page (no build step) |
| `figures/fig1.png` … `fig6.png` | Paper figures at original resolution |
| `assets/katex/` | Math typesetting styles and fonts |
| `.nojekyll` | Tells GitHub Pages to serve files as-is |

## Publishing

1. Create a public repository named `paper-composite-reward-tool-using-llm-orchestrators` under `capxarchitect` and upload these files to the root of the `main` branch.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, and save.
4. The page goes live at https://capxarchitect.github.io/paper-composite-reward-tool-using-llm-orchestrators/ within a minute or two.
